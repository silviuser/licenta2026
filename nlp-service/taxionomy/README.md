# ESCO Taxonomy Datasets

This directory holds the European Skills, Competences, Qualifications and Occupations (**ESCO v1.2.1**) classification datasets in CSV format.

### Expected Directory Layout:
```
taxionomy/
├── ESCO dataset - v1.2.1 - classification - en - csv/
│   ├── skills_en.csv
│   ├── skillSkillRelations_en.csv
│   └── occupationSkillRelations_en.csv
└── ESCO dataset - v1.2.1 - classification - ro - csv/
    ├── skills_ro.csv
    ├── skillSkillRelations_ro.csv
    └── occupationSkillRelations_ro.csv
```

### Download Instructions:
The datasets can be downloaded freely under the CC-BY-4.0 license from the official European Commission ESCO portal:
[https://esco.ec.europa.eu/en/use-esco/download](https://esco.ec.europa.eu/en/use-esco/download)
